# Security Policy

## Reporting Security Issues

**We take security seriously.** If you discover a security issue related to PCS, please report it responsibly.

### How to Report

**Email:** research@persistra.ai

**Please include:**
- Description of the issue
- Affected component or documentation
- Potential impact
- Suggested fix (if any)

**Response time:** We aim to acknowledge reports within 48 hours and provide a detailed response within 7 days.

### Scope

This security policy applies to:
- Public documentation and guidance
- Links to implementations and resources
- Security-relevant claims or statements

### Out of Scope

- Implementation vulnerabilities (report to specific repository maintainers)
- Third-party dependencies
- Theoretical attacks without proof of concept

## Vulnerability Disclosure Timeline

**If a security issue is confirmed:**

1. **Day 0:** Acknowledgment sent to reporter
2. **Day 1-7:** Validation and impact assessment
3. **Day 7-30:** Fix development and testing
4. **Day 30:** Coordinated disclosure (if applicable)
5. **Day 30+:** Public disclosure and update

**We follow responsible disclosure practices** and will credit reporters (unless anonymity is requested).
